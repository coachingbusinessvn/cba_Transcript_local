ViTranscript

Chuyển hội thoại tiếng Việt thành văn bản — chạy hoàn toàn trên máy bạn.

1. Chọn file audio / video

Kéo thả file vào đây
hoặc bấm để chọn · mp3, m4a, wav, mp4, mov, …

Hàng đợi file (desktop)

    Nhiều file chạy tuần tự (1 job/lần). Bấm mục đã xong để xem lại kết quả.

    2. Tùy chọn

    Nên nhập đúng số người (vd. 2). 0 = tự đoán (dễ tách quá nhiều trên file dài).
    Lần đầu tải model dấu câu ~110 MB.
    Định dạng sai => đúng hoặc một từ khóa mỗi dòng, ví dụ nờ vi đi a => NVIDIA và Vinamilk.

    3. Chạy transcript

    0% — Đang chuẩn bị…

    4. Kết quả

    Thời gian Người nói Nội dung
    Không có câu nào.
